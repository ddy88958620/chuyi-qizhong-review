# 初一上 · 期中在线复习（生物 / 历史 / 道法 / 地理 / 语文 / 数学 / 英语）

把 2026-2027 学年第一学期期中复习资料按学科分门别类整理成的**纯静态在线复习站**；历史、地理、生物、道德与法治已增加 2024 秋启用的人教版/统编版七上目录入口、知识主线、重要考点和高频题型板块；旧校内或旧版本资料保留并明确标注待迁移。
无需构建、无需后端、无需联网，直接打开 `index.html` 就能用；部署到 GitHub Pages 后可手机随时复习。

## 功能

- 七科分栏 + 板块切换，移动端自适应
- 全站搜索（点顶栏 🔍 或 `Ctrl/Cmd + K`），新增三科自动进入索引
- 选择题即时判分、错题筛选、重做（地理与语文 / 数学 / 英语每题附解析）
- 抽背卡片随机抽取、显示/隐藏答案（全站 279 张，语文 / 数学各 55 张、英语 55 张）
- 「遮罩速记」盖住知识点，点一下揭开
- 深浅色主题切换
- 掌握情况：抽背卡 / 填空 / 答案对照点「✓ 已掌握」，或选择题答对即计入进度；进度存本机 `localStorage`，不上传
- 学生视图：教材页码、官方题号、来源池等审计信息收进题目右上角 `ⓘ` 角标，点击后展开，不占用主要学习版面

[纸质教材复核清单](docs/paper-textbook-verification-2026.csv) 为四科 459 道题逐题记录电子教材页脚匹配、教材页图、纸质教材页码、复核人和日期；纸质教材印次未由学生实物逐页确认前，`physical_visual_check` 保持 `pending`。

## 官方试卷逐题导入门槛

拿到三河市或河北同版本地区的官方试卷原件后，先填写 [官方试卷逐题导入模板](docs/official-exam-import-template.csv)，再运行：

```bash
python3 tools/validate_official_exam_import.py
```

只有同时填写官方题号、原件地址与文件 SHA-256、题目图片、纸质教材精确页码和复核人信息的记录，才允许后续把题目状态升级为 `verified`；公开教辅页面题号不能替代官方题号。
校验器还会检查科目与教材版本是否匹配，并要求已核验原件的地区字段属于河北省或三河市。
